

## 목표
ERP Test의 영업관리 매뉴얼과 동일한 시각 가이드 형식으로, 본 앱(반출/가스)에 매뉴얼 페이지를 추가합니다. **현재 구현된 UI 기준으로만** 작성하고, 코드 로직 추정/확장 설명은 하지 않으며, 불확실한 부분은 "확인 필요"로 표기합니다. 기존 [반출점검]/[교정가스] 기능은 일절 수정하지 않습니다.

## 작성 원칙 (이번 변경의 핵심)
- 화면에 실제로 보이는 메뉴/버튼/필터/컬럼/팝업만 설명
- 내부 함수명, 자동 계산 로직, DB 스키마, 권한 매트릭스는 매뉴얼 본문에 쓰지 않음
- "왜 이렇게 동작하는지"는 화면에서 관측 가능한 범위만 기술
- 불명확한 항목은 본문에 **🔍 확인 필요** 인라인 표기

## 페이지 공통 레이아웃
- 상단: 페이지 타이틀 + 우측 `FileDown` 버튼 → `window.print()`
- `@media print`로 사이드바·헤더·인쇄 버튼 숨김, A4 세로 최적화
- 섹션 카드는 `page-break-inside: avoid`

## 반출점검 매뉴얼 본문 (UI 기준만)

**필독 안내 (NoticeBox)**
- 점검 결과는 발생 즉시 입력
- 1차/완료 보고서는 화면 안내에 따라 작성
- (자동 상태 전환/내부 규칙 서술 금지)

**섹션**
1. 로그인 / PWA 설치 — `/login`, `/install` 화면 캡처식 모형
2. 대시보드 — 현재 표시되는 KPI 카드 명칭만 나열, 의미 정의는 **🔍 확인 필요**
3. 현황표 — 화면에 보이는 필터·정렬 버튼, 컬럼명, 행 클릭 동작
4. 1차 점검보고서 — 입력 필드, 사진 첨부, 저장 버튼 위치 (서명/검증 규칙은 **🔍 확인 필요**)
5. 완료 점검보고서 — 화면 흐름, 다운로드 버튼 위치 (다운로드 결과 포맷은 화면 표기 그대로)
6. 알림센터 — 알림 종류·읽음 처리 UI

## 교정가스 매뉴얼 본문 (UI 기준만)

**필독 안내 (NoticeBox)**
- 입고/사용 발생 시 현황표에 즉시 반영
- 정도검사 일자/유효기간은 실측 즉시 입력
- 셀 메모는 셀 단위로 저장됨 (우클릭 → 메모삽입)

**섹션**
1. 현황표 — 컬럼 그룹(분석기 / 가스상 정도검사 / 유속계 정도검사 / 비고사항), 사업장·호기 병합, 조건부 색상이 화면에 어떻게 보이는지
2. 인라인 편집 — 셀 클릭 → 입력 → Enter/저장
3. 셀 메모 — 우클릭 → "메모삽입" → 저장 → 셀 우상단 빨간 모서리
4. 업로드 — `/calibration-gas/upload` 화면의 파일 선택, 검토 진입
5. 검토 — 매칭 화면에서 사용자가 클릭하는 버튼 위주
6. 이력 / 알림 / 엑셀 다운로드 — 버튼 위치와 클릭 결과(파일 저장)만 기술
7. 자동 계산/주기 등 내부 로직은 본문에 서술하지 않음 (필요 시 **🔍 확인 필요**)
