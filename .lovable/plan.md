## Section 1 새 구성

**제목:** `1. [→] 로그인` (LogIn 아이콘 포함, 기존 SectionCard num=1 사용)

**본문 (번호 매김 단계):**
1. 앱을 열면 로그인 화면이 표시됩니다.
2. **사번**을 입력합니다. (예: 1189101)
3. **이름**을 입력합니다. (예: 홍길동)
4. **로그인** 버튼을 누릅니다.

**알림 박스 (Bell 아이콘, 회색 톤 Callout):**
> 사번과 이름은 관리자가 등록한 정보와 정확히 일치해야 합니다. 로그인이 안 될 경우 관리자에게 문의하세요.

**모형 화면 (MockScreen, 모바일 폭 ~280px 중앙 정렬):**
- 상단 상태바 영역 (`9:41` / 우측 점)
- 타이틀: **반출점검·교정가스 관리** (※ 첨부 이미지의 "DXG 현장관리"를 이 문구로 변경)
- 입력 필드 1: 라벨 "사번" + 박스 안 텍스트 `1189101`
- 입력 필드 2: 라벨 "이름" + 박스 안 텍스트 `홍길동`
- 체크박스 + "정보 저장" + 옆에 작은 "클릭" 말풍선
- 빨간 테두리로 강조된 **로그인** 버튼 (ClickPoint 대신 버튼 자체에 빨간 ring)
- 모형 하단 캡션: *로그인 화면*

**기존 PWA(`/install`) 모형은 제거** — 첨부 이미지에 없으므로 이번 변경에서 1번 섹션은 로그인만 다룸. (PWA 안내가 필요하면 추후 별도 섹션으로 분리 가능, 이번엔 손대지 않음)
